# Contributing

Discuss changes in a pull request. Run the documented synthetic suite and publication scanner. Include a source/protocol rationale for scientific changes and distinguish bug fixes from new study designs. Keep participant groups intact across fitting, tuning, calibration and evaluation. Record seeds and dependency versions. Never add participant records, predictions, checkpoints, private paths, correspondence or attestations. Use entirely invented fixtures. Synthetic metrics must carry a software-test label.

Do not alter a historical freeze or imply that the public package is byte-identical to it. New experiments need a new protocol/version, approved access and researcher execution. Do not execute dataset analyses from an AI session. Licensing remains reserved; contributor and institutional rights must be resolved before adopting an open-source license. No automatic merge is configured by this release.
