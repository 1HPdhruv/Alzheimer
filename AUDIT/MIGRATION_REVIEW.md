# Source migration review

Original research files remain unchanged. This is a new portable source release, not the original immutable run freeze. Package imports are mapped from historical `src`, `experiments`, `multimodal_benchmark` and `temporal_multimodal` to `yoad`; feature helpers move into `yoad.features`. Benchmark default outputs are relative to the invocation directory. Existing synthetic library tests/fixtures are extracted where historical tests also required excluded private runners. Missing test constants were restored from the original module. No scientific rules, hyperparameter grids, seeds or label policies are changed. Unverified numerical annotations are removed from two module docstrings; one test whitespace line is normalized. The unused temporal report template with fixed historical scores is excluded.

The initial broad string migration failed tests and was replaced by import-only rewriting. Earlier failed runs are local audit evidence; only the final verified release is staged. Original ASTs and migrated ASTs are compared after normalizing imports (and the documented runner root assignment). Extractions are identified rather than claimed byte-identical.
