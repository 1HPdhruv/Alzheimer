# Data governance

This release contains source, synthetic fixtures, configurations and newly written audit documentation. It excludes ADNI/NACC participant-level tables, MRI images, private derivatives, folds, individual predictions, fitted model artifacts, credentials, correspondence and attestations. Git LFS is not used.

Local project records distinguish AI-assisted code/document work from researcher execution of participant-level analysis. This release follows that boundary and does not resolve historical authorization disputes. Provider/institutional decisions and file-specific aggregate disclosure review must be recorded by the responsible investigator; no signed agreement or clearance is asserted here.

Obtain controlled-access data separately through [ADNI](https://adni.loni.usc.edu/) and [NACC](https://naccdata.org/). Public availability of another repository does not authorize taking participant data from it. Respect the actual accepted agreements and publication requirements. Keep datasets and generated private outputs outside this checkout, on institutionally approved storage. A trained KNN imputer or checkpoint may retain private training information.

Suppression code exists, including a historical small-cell floor, but a floor is not a complete disclosure assessment. Complementary cells, linked tables and figures require review. No historical numerical tables or figures are republished in this release.
