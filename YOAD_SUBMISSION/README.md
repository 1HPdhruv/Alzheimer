# YOAD research submission package

This package organizes the existing research into six milestone checkpoints. It preserves the difference between working software, synthetic tests, previously reported participant-level analyses, blocked verification and future submission/acceptance evidence. It introduces no experiment, methodology, hypothesis, manuscript text or acceptance claim.

The percentages are requested checkpoint labels, not completion measurements. Existing source and configurations remain canonical at repository root; links avoid duplicate code trees. Selected audited public notes are copied byte-for-byte for faculty navigation. Commands in copied reproducibility notes run from the repository root. Private manuscripts, result values, datasets, predictions, checkpoints, correspondence and signed records remain outside Git.

Navigate the [master tracker](SUBMISSION_MASTER_TRACKER.md), [complete file inventory](FILE_INVENTORY.csv), [exact folder tree](FOLDER_TREE.md) and [organization validation report](VALIDATION_REPORT.md).

| Checkpoint | Package location | Current boundary |
|---|---|---|
| Literature review — 10% | [01](01_LITERATURE_REVIEW/README.md) | Bounded public summaries available; final literature/novelty verification incomplete |
| Experimentation/simulation — 30% | [02](02_EXPERIMENTATION/README.md) | Existing implementations and synthetic evidence available; private verification blocked |
| Analysis/inference — 50% | [03](03_ANALYSIS/README.md) | Historical result selectors catalogued; no numeric result value approved for copying |
| Paper drafting — 70% | [04](04_PAPER_DRAFT/README.md) | Latest inspected conference candidate and journal alternatives registered privately |
| Submission — 80% | [05](05_SUBMISSION/README.md) | PENDING final approval, venue package and receipt; no portal action |
| Acceptance — 100% | [06](06_ACCEPTANCE/README.md) | PENDING official acceptance, review, final forms and publication evidence |

Status values apply to the named deliverable, not the whole milestone. READY can mean a reviewed software implementation or an accurate status note; it never certifies clinical performance or manuscript approval. The historical 369-test report is class C evidence from the prior audited release, not new participant-level research. Classes A/B/C/D and remaining gates are retained in the copied experiment-status ledger.

Inventory scope includes every original workspace entry by metadata, every canonical public file and each new package artifact. Content review focused on the published assets and selected status/manuscript/result-provenance candidates. Unreviewed private files are not scientifically adjudicated: they remain withheld. Public opaque IDs for restricted filenames map to the local private inventory; no workstation account path, private log or suppressed result is exported.

Reserved-rights licensing is unchanged. Read the existing [publication audit](../PUBLICATION_AUDIT.md), [data governance](../docs/data_governance.md) and [source manifest](../AUDIT/SOURCE_MANIFEST.csv). Those audits describe their original release snapshot; this package adds organization records without rewriting those authoritative historical files.
